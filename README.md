## 📖 Project Overview
This project is a fully fledged Admin Dashboard designed to handle complex data visualization and user management interfaces. 

Unlike standard landing pages, this project required a rigid yet flexible layout system. To achieve this, I built my own **Custom CSS Utility Framework** (`framework.css`), bridging the gap between vanilla CSS and utility-first frameworks like Tailwind CSS.

---

## ✨ Key Features
- **Custom Utility Framework:** Developed a proprietary CSS framework to handle margins, paddings, colors, and layout properties efficiently.
- **Advanced Grid Layouts:** Heavily utilized **CSS Grid** to construct the complex main content area, allowing widgets to position themselves intelligently across varying screen widths.
- **10+ Custom Widgets:** Designed multiple UI components including:
  - Yearly Targets & Progress Bars
  - Ticket Statistics Counters
  - Latest News & Tasks Lists
  - Project Progress Timelines
- **Responsive Data Tables:** Built a mobile-friendly HTML table to display project statuses, client data, and pricing without horizontal scrolling issues on small devices.
- **Sidebar Navigation:** A sticky, fully responsive sidebar that collapses smoothly on mobile viewports.

---

## 🛠️ Tech Stack & Tools
- **Markup:** HTML5 (Semantic Structure)
- **Styling:** CSS3 (CSS Grid, Flexbox, CSS Variables)
- **Architecture:** Custom Utility Classes (`framework.css`)
- **Typography & Icons:** Google Fonts (*Open Sans*), Font Awesome
- **Version Control:** Git & GitHub

---

## 🧠 Key Learnings
Building this dashboard was a massive step forward in scalable web development. I learned how to:
1. Architect a reusable CSS utility system from scratch, drastically reducing code duplication.
2. Master CSS Grid (`d-grid`, `gap-20`) to create complex, mosaic-style layouts that are impossible or overly complicated with Flexbox alone.
3. Handle overflow and styling for large data tables on mobile devices.
4. Manage multiple UI states and z-indexes within a dense application interface.
